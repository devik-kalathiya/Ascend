# Real-Time Collaborative Whiteboard

I want to build a real-time collaborative whiteboard where multiple users can draw on the same canvas. I know HTML, CSS, and basic JavaScript. I want to use vanilla JS only — no frameworks.

The whiteboard should:
- Let users draw freehand with a mouse
- Show the drawing to other connected users in real-time
- Have a clear-canvas button
- Support different colors

My skill level: HTML/CSS/JS beginner-intermediate.
